WebPen Presenter bookmarklet

A bookmark that puts the laser, highlighter, pen and quick notes over any web page. Tap it on the page you are sharing.

1. Copy the code

2. Make the bookmark (iPad Safari, once)

  1. Bookmark this page: share button, Add Bookmark, name it Presenter, save.
  2. Open the bookmarks list, tap Edit, tap Presenter.
  3. Clear the address field, paste the code, tap Done.

On a computer: show the bookmarks bar, add a bookmark named Presenter, paste the code as its address. Or drag this link to the bar: Presenter.

3. Use it

  1. Open any website in Safari.
  2. Open the bookmarks, tap Presenter. The Pointer chip appears bottom-left.
  3. Laser points and writes quick notes that fade; Mark and Pen stay until Clear; Erase, Undo, Red / Blue, Thick as in the lessons. Share the screen as usual.
  4. After a reload or on a new site, tap the bookmark again.

Limits: only inside a web page (not the home screen, not apps, not Safari's PDF viewer). A few sites that forbid outside scripts will ignore it.
