WebPen Presenter bookmarklet

A bookmark that puts a laser pointer, highlighter, pen and fading quick notes over any web page, so a screen share shows what you point at and write. Made for an iPad with an Apple Pencil; a mouse works too.

1. Copy the code

2. Make the bookmark on the iPad (Safari, once)

  1. With this page open, tap the Share button (the square with an arrow), then Add Bookmark. Name it Presenter, keep the location as Favorites, tap Save.
  2. Tap Copy the code above.
  3. Open the bookmarks: tap the book icon (in the sidebar or the toolbar). Make sure the Bookmarks tab is selected, then tap Edit at the bottom.
  4. Tap the Presenter bookmark. Tap the address field under the name, tap it again and choose Select All, then Paste. The field now starts with javascript:.
  5. Tap Done, then Done again.

Optional, saves a tap every time: Settings, Safari, turn on Show Favorites Bar. The Presenter bookmark then sits under the address bar on every page.

Make the bookmark on a computer

Chrome or Edge: press Ctrl+Shift+B (Mac: Cmd+Shift+B) to show the bookmarks bar, then drag this button onto it:

Presenter

If dragging does not work, right-click the bookmarks bar, choose Add page, name it Presenter and paste the code as the URL.

3. Use it

  1. Open the website you want to present in Safari and start the screen share.
  2. Tap the Presenter bookmark (from the Favorites bar, or book icon then Presenter). The tool bar appears bottom-left.
  3. Laser points and writes quick notes that fade on their own; a quick pencil tap presses the button under it. Mark and Pen stay until Clear; Red/Blue and Thick change the pen; Erase rubs out part of a line; Undo takes back the last stroke; Finger lets fingers draw too; Hide leaves a small Pointer chip to bring the bar back.
  4. Fingers keep scrolling and tapping the page while the pencil draws. After a reload or on another site, tap the bookmark again.

Limits

  • Works only inside a web page: not on the home screen, in other apps, or in Safari's PDF viewer.
  • Sites that forbid outside scripts (a strict Content Security Policy) ignore the bookmark: GitHub, Wikipedia, YouTube, Google Docs and Slides, GeoGebra. For those, use the Chrome extension on a computer. News sites, Desmos, Khan Academy, Canvas LMS and Excalidraw accept it.
  • Inside an embedded video or calculator (an iframe) the pencil reaches the embed, not the overlay. The extension handles that; the bookmark does not.

The script draws only in your browser and sends nothing anywhere. Privacy.
